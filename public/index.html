Bước 1 · Chọn môi trường

Token và webhook của Test mode và Production là hai bộ riêng. Đổi môi trường thì nhập lại token và webhook tương ứng.

Bước 2 · API Token

  1. Vào my.sepay.vn → Cấu hình công ty → API Access (nếu dùng Test mode, bật Test mode ở sidebar trước).
  2. Bấm + Thêm API, đặt tên (vd “Web thu chi”), trạng thái Hoạt động, bấm Thêm.
  3. Sao chép token và dán vào ô dưới.

Bước 3 · Webhook

  1. Bấm Tạo Secret Key bên dưới rồi Sao chép.
  2. Vào my.sepay.vn → Webhooks → + Thêm webhooks.
  3. Sự kiện: Cả hai (tiền vào và tiền ra). Chọn tài khoản ngân hàng cần theo dõi. Không bật “Chỉ gửi khi có mã thanh toán”.
  4. URL nhận: dán URL bên dưới. Kiểu nội dung: application/json.
  5. Bảo mật: chọn HMAC-SHA256, dán Secret Key. Bật Tự động gửi lại khi server trả lỗi. Lưu, rồi bấm Gửi thử.

Bước 4 · Lưu và kiểm tra

Nhật ký webhook (30 lần gần nhất)

Mỗi lần SePay gọi tới tool đều được ghi ở đây, kể cả khi bị từ chối. Trống nghĩa là SePay chưa gọi lần nào: kiểm tra webhook đã bật, đúng URL và đúng tài khoản.
