Tài khoản Goship

Mỗi tài khoản là một shop trên goship.io, có Access Token, địa chỉ lấy hàng và URL webhook riêng. Access Token lấy ở shop.goship.io (Sandbox: dev-shop.goship.io) → Cài đặt → Kết nối API.

Xác minh số điện thoại qua eSMS

Hệ thống sinh mã OTP, gửi qua SMS brandname, Zalo ZNS, hoặc Zalo trước rồi tự chuyển SMS nếu Zalo lỗi, và tự kiểm tra mã khách nhập. Mỗi tài khoản eSMS có ApiKey, brandname và Zalo OA riêng. Phần mềm khác dùng qua API key có quyền OTP (tài liệu /docs#otp).

Giới hạn chống spam: mỗi số tối đa 1 mã mỗi 60 giây và 5 mã mỗi giờ; mỗi mã nhập sai tối đa 5 lần.

Kết nối SePay

Mỗi kết nối là một tài khoản SePay (một công ty trên my.sepay.vn), có API Token, URL webhook và Secret Key riêng. Mọi tài khoản ngân hàng đã liên kết trong tài khoản SePay đó tự hiện ra sau lần đối soát đầu. Muốn theo dõi thêm công ty khác, bấm + Thêm kết nối.

Cách khai báo một kết nối

  1. API Token: my.sepay.vn → Cấu hình công ty → API Access → + Thêm API, trạng thái Hoạt động, sao chép token. Token của Test mode và Production là hai bộ riêng.
  2. Webhook: trong kết nối bấm Tạo Secret Key và Lưu. Trên my.sepay.vn → Webhooks → + Thêm webhooks: sự kiện Cả hai, chọn tài khoản ngân hàng, URL = URL webhook của kết nối, kiểu nội dung application/json, bảo mật HMAC-SHA256 với cùng Secret Key, bật tự gửi lại khi lỗi.
  3. Bấm Gửi thử trên SePay, rồi Kiểm tra và Đối soát ở đây. Nhật ký webhook của từng kết nối cho biết mỗi lần SePay gọi có được nhận không và vì sao.

API cho bên thứ 3

Cấp API key để phần mềm khác (kế toán, CRM, website bán hàng…) đọc giao dịch, số dư, báo cáo thu chi hoặc tạo yêu cầu thu tiền QR. Gửi cho đối tác: API key và link tài liệu /docs.
